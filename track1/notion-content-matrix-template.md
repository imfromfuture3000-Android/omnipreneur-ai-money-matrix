# Content Matrix Master Database – Notion Template Structure

## Database Properties (Create these in Notion)

| Property Name | Type | Description |
|---------------|------|-------------|
| Title | Title | Main piece name |
| Source Type | Select | YouTube / Podcast / Blog / Call / Other |
| Source URL | URL | Original link |
| Status | Status | Idea / Processing / Generated / Published / Archived |
| Viral Score | Number | 1–10 AI predicted |
| Primary Hook | Text | Best hook |
| Platforms | Multi-select | Shorts, X, LinkedIn, Email, Newsletter, Blog |
| SEO Keywords | Multi-select | Target keywords |
| Publish Date | Date | Scheduled or actual |
| Notes | Text | Internal notes |
| Generated Assets | Files & media | Attachments of scripts, etc. |
| CTA | Text | Main call-to-action used |
| Performance | Number | Views / Engagement (manual or Zapier later) |

## Views to Create
1. **Kanban by Status** – workflow board

3. **High Viral Score** – filter Viral Score ≥ 7

## How to Use
1. Duplicate this structure into your Notion workspace
2. For every long-form piece, create a new database entry
3. Paste the source into a linked page or AI prompt
4. Run Content Matrix prompts
5. Fill the properties and attach outputs
6. Use views to manage pipeline
