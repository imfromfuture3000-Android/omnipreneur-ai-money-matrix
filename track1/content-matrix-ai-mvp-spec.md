# Content Matrix AI – MVP Specification (v0.1)

## Core Job-to-be-Done
Take one long-form asset (YouTube transcript, podcast, blog, Zoom recording) and auto-generate:
- 5–10 Shorts/Reels scripts + hooks + captions
- Twitter/X Thread (8–12 posts)
- LinkedIn carousel outline + post
- Email newsletter version
- Notion database entry with tags, SEO titles, viral score
- 3 alternative hooks ranked by predicted engagement

## Tech Stack (No-Code First)
- Frontend / Auth / Payments: Bubble or Softr + Stripe
- AI Layer: OpenAI GPT-4o / Claude 3.5 via API
- Storage: Airtable or Notion API
- Automation: Make.com or Zapier
- File upload: native or Uploadcare

## User Flow
1. Upload transcript or paste text (or YouTube URL → auto-transcript via Whisper/API)
2. Select target platforms + tone (professional / casual / educational)
3. Click “Generate Matrix”
4. Review / edit outputs in dashboard
5. One-click export to Notion, Buffer, or download as ZIP
6. Save as reusable “Repurposing Recipe”
